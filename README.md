# Haunted Hallways

A 3D first-person horror escape game. Wake up locked in a creepy old house, sneak past **Grandma Hettie** (fast, hears everything) and **Grandpa Orville** (slow, tough, half-deaf), find keys and tools, and escape by the front door, the car or the boat. All characters and art are original.

**Play / install:** https://joshionclaude.github.io/haunted-hallways/

- **Android:** download `HauntedHallways-Android.apk` from the Releases page and install it.
- **Windows:** download `HauntedHallways-Windows.zip`, unzip, run `Haunted Hallways.exe`.
- **iPhone / iPad / Mac / Chromebook / any browser:** open the link above, then *Share > Add to Home Screen* (or the browser's *Install app*).

Controls: WASD move · Shift run (loud) · C crouch · E use · 1-8 items · Q drop · N notebook · Click shoot/throw. Touch: joystick + buttons.

Source parts are in `src/` (`python build.py` assembles `index.html`).
